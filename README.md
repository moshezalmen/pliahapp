# פּליה אַקאַונטינג אַפּ

אַן מודרן, פיצ'ורפול אַקאַונטינג אַפּליקעישן בנוי מיט Tailwind CSS און Vanilla JavaScript.

## פיצ'ערס

### 📊 לעדזשער
- **לעדזשער רעקארדס** - מאנאגע הכנסות, הוצאות, און חובות
- **סטאטוס טראקינג** - מארק קלאידנטן אלס "באצאלט" אדער "אומבאצאלט"
- **סימארי קארדס** - ביאור אף כל הכנסות, חובות, הוצאות, און מעשר
- **פילטערינג** - זוך בנאמע, פילטער בדאטע רענדזש און סטאטוס
- **CSV עקספאָרט** - דאונלאד אלע דעטעילס אלס CSV

### 📈 רעפּאָרטן
- **מאנטלי סימארי** - זע כל חודש זינוד
- **קאטעגאריע אנאליזע** - בראקדאון דורך שרייבן, עדיטינג, קונסולטינג, וו.
- **פּראפיט & לאס** - שטיק פּראפיט/לאס און מעשר קלקולאציע

### 📄 אינוואיסן
- **אימפארטירן קלאידנטן** - שנעל אימפארטיר אונפעיד בלאנסעס אלס אינוואיסן
- **אינוואיס טעמפלעטס** - יוז פּרעפיל אינוואיס טעמפלעטס
- **PDF עקספאָרט** - דאונלאד אינוואיסן אלס PDF
- **פּרינט סעפּארטעד** - אפטימיזד פּרינט לייאות

### 🔄 ആNDO/REDO
- **וועריינלימטעד ונדו** - רעווַינד קאנגעס
- **וורקפלאו ריקאווערי** - ריטור צו פּריער סטייטן
- **ויזועאל היסטאָריע** - זע אלע עקשנס

### 🌙 דארק מאד
- **טוגל דארק מאד** - מענו בילטן אפציע לנייטנייט וורקינג
- **בעסער יי ראנק** - אפטימיזד קולעס פאר דארק מאד

## טעכנאָלאגיעס

- **Tailwind CSS** - יוטיליטי-פירסט CSS
- **Vanilla JavaScript** - נאו טראמפליקייטיוו אין ממס
- **localStorage** - דעטע פּערסיסטענץ
- **html2pdf.js** - PDF עקספאָרטינג

## להתחיל

1. קלאָנע דעם רעפּאָ:
```bash
git clone https://github.com/moshezalmen/pliahapp.git
```

2. אפן `index.html` אין דיין בראוזער

3. שטאַרט מאנאגינג דיין אַקאַונטס!

## דעטע סטאָרעדזש

אלע דעטעילס איז סטאָרעד לאקאלי אין `localStorage`:
- `pliahapp_ledger` - הלעדזשער עקנטריעס
- `pliahapp_history` - ונדו/רידו היסטאָריע
- `pliahapp_invoices` - סייווד אינוואיסן
- `pliahapp_darkmode` - דארק מאד סעטינג
